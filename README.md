## Portifolio Particular

O objetivo desse projeto é construir um portifolio para uso pessoal e práticar Frontend.

## Tecnologias Utilizadas:
- React.js
- TailwindCSS
- Shader Gradient 

## Como instalar:

- Requisitos: Ter Node.js instalado

- Abra o terminal e rode "npm install" no diretorio do projeto
- Rode em seguida "npm run dev" ainda no diretorio do projeto
